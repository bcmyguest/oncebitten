# oncebitten

Turns repeated agent mistakes into rules that git enforces.

```sh
npx oncebitten --version
npm install --global oncebitten
```

This package is a launcher. The binaries come from the matching platform package
(`oncebitten-linux-x64`, `oncebitten-linux-arm64`, `oncebitten-darwin-x64`,
`oncebitten-darwin-arm64`, `oncebitten-win32-x64`), which npm installs as an
optional dependency. Do not pass `--omit=optional`.

Docs: https://bcmyguest.github.io/oncebitten/ · Source: https://github.com/bcmyguest/oncebitten
